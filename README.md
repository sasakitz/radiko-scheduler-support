# ラジオの時間 — Radiko Scheduler

Googleカレンダーの番組予定に合わせてradikoのライブ放送を再生するChrome拡張機能の利用案内です。radikoおよびGoogleの公式拡張機能ではありません。

現在、Chrome Web Storeへの公開準備中です。公開後、このページにインストール先を掲載します。

[プライバシーポリシー](PRIVACY.md) / [お問い合わせ・不具合報告](https://github.com/sasakitz/radiko-scheduler-support/issues)

Chrome 120以降が対象です。インストール後、拡張のポップアップから「設定」を開いてカレンダーを接続してください。

## カレンダーを接続

Googleカレンダーで「設定」→「マイカレンダーの設定」→ 対象カレンダー →「カレンダーの統合」→ **「iCal形式の非公開URL」** をコピーし、拡張の設定に貼り付けて「保存して同期」を押します。

ラジオ専用のカレンダーがおすすめです。カレンダーを一般公開する必要はありません。組織アカウントでは管理者の設定により非公開URLを取得できない場合があります。手順は[Googleの公式ヘルプ](https://support.google.com/calendar/answer/37648?hl=ja)にも記載されています。

URLはカレンダーを閲覧できる秘密のリンクです。この拡張は `chrome.storage.local` に保存し、Googleからの取得だけに使用します。Chromeの同期ストレージや独自サーバーには送信しません。コンテンツスクリプトからストレージへのアクセスも制限しています。接続解除でURL・予定・履歴を削除します。OS上のブラウザプロファイル自体は暗号化する設計ではないため、URLを共有したりリポジトリに保存したりしないでください。

## 番組を登録

Googleカレンダーに、番組の**開始・終了時刻**を指定した予定を作り、説明欄または場所にradikoのURLを入れます。

既存の予定で「場所」に放送局のライブURLを記載している場合も、そのまま利用できます。説明欄への転記は不要です。両方にURLがある場合は、説明欄で認識したURLを優先します。

```text
タイトル: お気に入りのラジオ番組
日時: 毎週日曜 15:00〜16:00
説明: https://radiko.jp/#!/live/TBS
```

以下のURLを認識します。

- 放送局のライブURL：`https://radiko.jp/#!/live/TBS`
- 共有URL：`https://radiko.jp/share/?sid=TBS&t=20260927150000`
- 番組URL：`https://radiko.jp/#!/ts/TBS/20260927150000`

radikoの「Googleカレンダーに追加」で説明欄に入る番組URLも対象です。**どの形式でも放送局を抽出し、カレンダーの開始時刻にライブ放送を再生します。** タイムフリー再生や録音は行いません。番組名だけでは放送局を特定しません。終日予定、URLのない予定、終了時刻のない予定は対象外です。

繰り返し予定、除外日、個別の日時変更、キャンセルに対応します。日時はカレンダーのタイムゾーンに従い、画面には日本時間で表示します。タイムゾーン指定のない予定はカレンダーの `X-WR-TIMEZONE`、それもない場合は日本時間として扱います。

## ON / OFF

- 拡張のポップアップで「予約再生」を切り替えます。ツールバーのバッジにも `ON` / `OFF` が表示されます。
- **Alt + Shift + R** なら、ポップアップを開かず切り替えられます。割り当ては `chrome://extensions/shortcuts` / `edge://extensions/shortcuts` で変更できます。
- 初期状態はOFFです。OFF→ONに切り替えると、その時点で放送中の予定も途中から再生します。例えば12:00〜13:00の予定があれば、12:05にONにすると再生を開始します。一度再生・停止した番組も、終了前ならOFF→ONで再開できます。終了済みの予定は再生しません。
- OFFにすると、拡張が開いた再生中のradikoタブも閉じます。「今の再生を停止」なら予約再生はONのままで現在の再生だけを止めます。
- 「予定の終了時刻に再生を止める」は初期状態でONです。OFFの場合も、次の番組が始まれば前の拡張所有タブを閉じて切り替えます。
- 手動で開いたradikoタブは操作しません。拡張が開いたタブでも、別ページ・別の放送局へ移動していた場合は閉じません。

## 動作条件と制約

- **PCが起動し、ブラウザが動作している必要があります。** 拡張はPCをスリープから復帰させません。[Chromeのアラーム仕様](https://developer.chrome.com/docs/extensions/reference/api/alarms)により、開始・終了は数十秒以上遅れることがあります。ONにした後に始まった予定は、スリープ復帰時に開始から2分以内、かつ放送終了前の場合だけ自動再生します。それを過ぎても、OFF→ONに切り替えれば放送中の予定を途中から再生できます。
- 次の7日分を保持し、1分ごとにGoogleから再取得します。Google側のiCal更新が遅れることもあるため、直前に変更した場合は「更新」を押し、一覧への反映を確認してください。
- 通信エラー時は前回の予定を保持します。最終同期から24時間を超えると新たな再生を行いません。通信が切れている間の変更・取消は反映できません。
- 予定が重なったら、先に始まった番組を優先し、重なった予定を履歴にスキップとして記録します。同時刻は予定ID順で1件を選びます。
- radikoのログイン、聴取エリア、利用プランは通常のradikoと同じです。再生時は拡張専用のタブを前面に開きます。
- **ブラウザの自動再生制限により再生がブロックされる場合があります。** 事前にradikoを手動再生し、音量とサイト設定を確認してください。Edgeではradikoの「メディアの自動再生」を許可してください。手動再生を一度行っても、すべての環境で無人再生を保証するものではありません。[Chromeの自動再生ポリシー](https://developer.chrome.com/blog/autoplay)を回避する処理はありません。
- ボタンをクリックしただけでは成功扱いにしません。音声要素の時間進行とミュート状態を確認します。タブ自体・OSのミュートやスピーカーの状態までは確認できません。55秒程度で確認できなければポップアップの履歴に失敗を表示し、タブを残します。ページ読み込み自体が失敗した場合もウォッチドッグで検出します。
- radikoのページ構造が変更されると、`src/player.js` のセレクター修正が必要になる場合があります。

## 最初の動作確認

1. radikoを開き、対象局を手動で再生できることを確認します。
2. 2〜3分後に始まり、1分程度で終了するテスト予定をGoogleカレンダーに作ります。
3. 拡張の「更新」を押し、予定一覧に表示されたことを確認してONにします。
4. 予定時刻に専用タブが開き、音が出ること、終了時刻にタブが閉じることを確認します。
5. 次のテストでは再生中にOFFにして停止を確認します。
6. OFFのまま別の予定時刻を迎えても再生しないことを確認します。

ユーザーのカレンダー接続・radikoログイン・実際の音声出力を含めた確認は、この手順で行ってください。
