# ラジオの時間 — Radiko Scheduler

Radikoの番組表から番組を予約し、放送時間にライブ再生するデスクトップ向けブラウザ拡張です。番組表を使わない時刻固定予約や、Googleカレンダーの予定からの再生にも対応しています。radikoおよびGoogleの公式拡張機能ではありません。

[プライバシーポリシー](PRIVACY.md) / [お問い合わせ・不具合報告](https://github.com/sasakitz/radiko-scheduler-support/issues)

## インストール

<a href="https://addons.mozilla.org/ja/firefox/addon/%E3%83%A9%E3%82%B8%E3%82%AA%E3%81%AE%E6%99%82%E9%96%93-radiko-scheduler/"><img src="https://extensionworkshop.com/assets/img/documentation/publish/get-the-addon-178x60px.dad84b42.png" alt="Firefox Add-ons で入手" width="172"></a>

- **Chrome / Edge:** [Chrome Web Store](https://chromewebstore.google.com/detail/jjhpohehcgnaljoaglniejlkklflaegc)からインストールします。Chrome 120以降、または相当するChromium版Edgeが対象です。
- **Firefox:** [Firefox Add-ons（AMO）](https://addons.mozilla.org/ja/firefox/addon/%E3%83%A9%E3%82%B8%E3%82%AA%E3%81%AE%E6%99%82%E9%96%93-radiko-scheduler/)からインストールします。デスクトップ版Firefox 140以降が対象です。Android版は対象外です。

インストールしたらツールバーに拡張を固定し、アイコンからポップアップを開いて「設定」を選びます。設定画面には「番組予約」「Googleカレンダー」「再生方法」「通知設定」の4つのタブがあります。**最初にGoogleカレンダーを接続する必要はありません。** 番組表から直接予約できます。

## 番組表から予約する

1. 設定画面の「番組予約」タブで **「番組表から探す」** を開きます。
2. 地域と放送局を選び、**「番組表を取得」** を押します。地域は番組を探すための選択で、radikoの聴取エリアや会員プランは変わりません。
3. 曜日を選んで番組を探します。番組名を入力すると、取得した全曜日から検索できます。
4. 対象の **「この番組を予約」** を押すと、下の予約欄に番組名・放送局・開始／終了日時が入ります。
5. 「今回のみ」または「毎週（日本時間の同じ曜日）」を選び、内容を確認して **「予約を保存」** を押します。
6. 拡張のポップアップで **「予約再生」をON** にします。初期状態はOFFです。

日時は日本時間です。保存済みの予約は「保存した予約」から編集・削除できます。最大200件まで登録できます。放送局が表示されないときは「放送局一覧を更新」を押してください。

### 番組表の時間変更への追従

「Radiko番組表の時間変更に追従する」は初期状態でONです。対象の番組を番組表から一意に特定できた場合、開始・終了時刻の変更を予約に反映します。毎週予約も次の放送回を確認します。放送直前に時刻が変わる可能性がある場合は、ポップアップの予定一覧に反映されたことを確認してください。

番組表が未公開、対象が見つからない、候補が複数ある場合は、特定できるまで新たな再生を保留します。番組表に反映されない延長や、番組名と番組IDがともに変わった場合の追従は保証できません。時刻を固定したい予約は、このチェックを外してください。

### 時刻を手入力して予約する

番組表を使わず、同じ「番組予約」タブの予約欄に番組名・地域・放送局・開始／終了日時を入力して保存できます。「今回のみ」と「毎週」を選べます。番組表の照合が不要な予約にするには、「Radiko番組表の時間変更に追従する」をOFFにします。

「遅延（秒）」が空欄なら「再生方法」タブの自動調整設定に従います。`0`なら調整せず、数値を入れると開始と終了をその秒数だけ遅らせます。

## Googleカレンダーから再生する

Googleカレンダーの利用は任意です。拡張は予定を読み取るだけで、Google側の予定を追加・変更・削除しません。

### カレンダーを接続する

1. Googleカレンダーで「設定」→対象カレンダー→「カレンダーの統合」を開き、**「iCal形式の非公開URL」** をコピーします。[Googleの手順](https://support.google.com/calendar/answer/37648?hl=ja)も参照できます。
2. 拡張の設定画面で「Googleカレンダー」タブを開き、そのURLを貼り付けて **「接続して同期」** を押します。
3. カレンダーに、開始・終了時刻とradikoの放送局URLを含む予定を作ります。URLは説明欄または場所に入れます。

```text
タイトル: お気に入りのラジオ番組
日時: 毎週日曜 15:00〜16:00
説明: https://radiko.jp/#!/live/TBS
```

放送局のライブURLのほか、`https://radiko.jp/share/?sid=TBS&t=20260927150000` のような共有URLや、radikoの番組URLも認識します。URLから放送局を読み取り、**カレンダーの時刻にライブ放送**を再生します。タイムフリー再生や録音は行いません。番組名だけの予定、終日予定、終了時刻のない予定は対象外です。

Google由来の予定はカレンダーの時刻を使い、番組表の時刻変更には自動追従しません。追従させたい番組は「番組予約」タブで登録するか、次の方法で取込予約にします。Google側の更新が拡張に反映されるまで時間がかかる場合があります。直前に変更したときはポップアップの「更新」を押し、予定一覧を確認してください。

### Google予定を予約として取り込む

「Googleカレンダー」タブの **「Googleカレンダーの予定を取り込む」** から、予定を1件ずつ、または「未取り込みの予定をすべてインポート」で取込予約にできます。繰り返し予定はシリーズごとに1件へまとめ、終了条件・除外日・個別の変更なども保持します。番組表で対象を一意に特定できた場合は放送時刻を揃えて変更追従を有効にし、特定できない場合は元の時刻で固定します。

取込予約はブラウザの同期対象です。取り込み元のGoogle予定は重複再生しません。取込後にGoogle側の予定を編集しても、取込予約へは自動反映されません。接続を解除しても取込予約は残ります。取込予約を削除した場合、接続中の元予定は再び再生対象になります。

### 放送の遅延を調整する

Google予定の説明欄に独立した行で `遅延: 30秒` と書くと、開始・終了を30秒遅らせます。`遅延: 0秒` はその予定の調整を無効にします。

「再生方法」タブの「放送局データで遅延を自動調整する」をONにして「保存して同期」を押すと、radikoの公開放送局データにある遅延値を使用します。初期状態はOFFです。予約の遅延欄やGoogle予定の説明欄に有効な値があれば、そちらを優先します。音声を測定して補正する機能ではなく、再生準備や回線状況による追加の遅れは起こり得ます。

## 再生と通知

ポップアップの「予約再生」をONにすると、予約と対象のGoogle予定を再生します。**PCとブラウザを起動したままにしてください。** OFFにすると現在の再生も停止します。「今の再生を停止」は予約再生をONのまま現在の再生だけを止めます。ポップアップの「更新」で番組表とGoogle予定を再取得できます。

- 再生中は一時停止・再開、音量変更、ミュート・ミュート解除ができます。ポップアップを閉じても状態は続きます。一時停止中もライブ放送は進みます。
- 開始・再開時は約1.5秒でフェードイン、停止・終了・放送局の切り替え時は約1.5秒でフェードアウトします。同じ放送局の予約が切れ目なく続く場合は、再生を中断せず次の予約へ引き継ぎます。
- 「再生方法」タブの「予定の終了時刻に再生を止める」は初期状態でONです。一時停止中やミュート中も終了時刻に停止します。
- ツールバーのバッジは待機中の `ON` / `OFF`、再生中の `PLAY`、一時停止の `PAUS`、ミュートの `MUTE`、再生確認中の `...`、失敗の `ERR` などで状態を示します。実際にスピーカーから音が出ているかまでは判定できません。
- **Alt + Shift + R** で予約再生を切り替えられます。ショートカットは各ブラウザの拡張機能設定から変更できます。

### 通知設定

「通知設定」タブで、再生前の予告・再生開始・再生エラーの通知をまとめてON/OFFにできます。初期状態はON、予告は5分前です。予告は1〜1440分前で指定し、**「通知設定を保存」** を押します。OFFにすると3種類とも通知しません。

通知には番組名、放送局、遅延調整後の開始／終了日時（日本時間）が含まれます。再生開始通知は音声の進行を確認した後に表示します。通知の表示はブラウザ・OSの通知設定やスリープ状態にも左右されます。

## 他のデバイスとの同期と削除

保存した予約と取込予約は、ブラウザの同期機能を使い、同じブラウザの同じアカウントの他デバイスへ共有します。各デバイスでブラウザの拡張機能同期と、この拡張の「予約再生」を有効にしてください。Chrome同士、Edge同士、デスクトップFirefox同士が対象です。**Chrome・Edge・Firefox間の相互同期はできません。** 同期には時間がかかり、ポップアップの「更新」はブラウザのクラウド同期を強制しません。

Googleカレンダーの非公開URL、未取り込みのGoogle予定、予約再生ON/OFF、音量、通知設定、履歴やキャッシュは端末ごとに保持します。同期が無効・オフラインでも、そのブラウザに保存済みの予約は利用できます。保存できる予約は最大200件ですが、ブラウザの同期容量上限に先に達する場合があります。

個別の予約は「保存した予約」から削除できます。全件を削除する場合は **「予約をすべて削除…」** を押し、影響を確認して「全削除」と入力します。取込予約を含む削除は同期先にも反映され、元に戻せません。Googleカレンダーの取得予定や設定は残ります。Google接続を解除すると、その端末のカレンダーURL・取得予定・関連履歴を削除し、保存した予約は残します。

## 最初の動作確認と困ったとき

1. [radiko.jp](https://radiko.jp/)で聴きたい局を手動再生できることを確認します。radikoへのログインが必要な場合は、通常のサイトでログインします。
2. 設定画面で2〜3分後に始まり、1分ほどで終わる時刻固定予約を作ります。ポップアップの「更新」を押し、予定一覧に表示されることを確かめます。
3. 「予約再生」をONにし、開始時刻に音声が出ること、ポップアップの一時停止・再開・音量・ミュート操作、終了時の停止を確認します。

再生しない場合は、ポップアップの `ERR` 表示や「最近の動作」を確認してください。radikoで対象局を手動再生できるか、ログイン状態・聴取エリア・会員プラン・接続状態・ブラウザの自動再生設定・OSの音量を確認します。Edgeではradikoサイトの「メディアの自動再生」を許可してください。Firefoxで自動再生がブロックされる場合は、設定の「プライバシーとセキュリティ」→「自動再生」を確認してください。再生を確認できない場合、放送中の有効な予約について最大3回再試行します。状況が解消したらOFF→ONで再試行できます。

番組が始まらない場合は、ポップアップの予定一覧で「番組表未確認」「番組表未公開・公開待ち」「番組表反映待ち」「要確認・再生保留」などの表示を確認してください。番組表で対象を特定できない追従予約は再生を保留します。必要に応じて予約を編集し、番組表の対象を確認するか、時刻固定予約に変更してください。

PCのスリープ中やブラウザ終了中は動作しません。復帰時に開始から2分を超えている予定は自動開始しませんが、放送中ならOFF→ONで途中から再生できます。ブラウザのアラーム、配信元の更新、自動再生制限により開始が遅れることがあります。radiko側のページ構造が変わると再生できなくなる場合もあります。

## データとサポート

予約はブラウザの同期ストレージに保存します。カレンダーの非公開URL、未取り込みの予定、再生設定、通知設定と履歴は端末内に保存します。カレンダーURLはGoogleから予定を取得するために使用し、開発者のサーバーへ送信しません。非公開URLやアカウント情報を他人に共有しないでください。詳しくは[プライバシーポリシー](PRIVACY.md)をご覧ください。

不具合や質問は[GitHub Issues](https://github.com/sasakitz/radiko-scheduler-support/issues)で受け付けています。投稿は公開されます。カレンダーの非公開URL、ログイン情報、個人情報を含む予定を記載しないでください。
