# ラジオの時間 — Radiko Scheduler

Googleカレンダーの番組予定に合わせてradikoのライブ放送を再生するChrome / Edge / Firefox拡張機能の利用案内です。radikoおよびGoogleの公式拡張機能ではありません。

[プライバシーポリシー](PRIVACY.md) / [お問い合わせ・不具合報告](https://github.com/sasakitz/radiko-scheduler-support/issues)

## インストール

Chrome版は [Chrome Web Store](https://chromewebstore.google.com/detail/jjhpohehcgnaljoaglniejlkklflaegc) で公開しています。Chrome 120以降が対象です。EdgeでもChrome Web Storeからインストールできます。

Firefox版はデスクトップ版Firefox 140以降に対応しています。Firefox Add-ons（AMO）の公開URLは、このページではまだ案内していません。通常のFirefoxに継続してインストールするには、Mozillaによる署名済みアドオンが必要です。開発用の一時インストール手順は [本体リポジトリ](https://github.com/sasakitz/radiko-scheduler#readme) を参照してください。一時的なアドオンはFirefoxの再起動で削除されます。

インストール後、拡張のポップアップから「設定」を開いてカレンダーを接続してください。ツールバーに拡張を固定すると操作しやすくなります。

Firefox版では、インストール時にGoogleカレンダーの非公開URLとradikoの認証セッションに関するデータ利用への同意をFirefox標準画面で求めます。送信先はGoogleとradikoで、開発者への送信はありません。自動再生がブロックされる場合は、Firefoxの設定 → プライバシーとセキュリティ → 自動再生で音声の自動再生を許可し、再試行してください。

この案内は0.2.2の機能を含みます。遅延調整は0.2.2以降で利用できます。インストール済みのバージョンは各ブラウザの拡張機能管理画面で確認してください。

## カレンダーを接続

Googleカレンダーで「設定」→「マイカレンダーの設定」→ 対象カレンダー →「カレンダーの統合」→ **「iCal形式の非公開URL」** をコピーし、拡張の設定に貼り付けて「保存して同期」を押します。

ラジオ専用のカレンダーがおすすめです。カレンダーを一般公開する必要はありません。組織アカウントでは管理者の設定により非公開URLを取得できない場合があります。手順は[Googleの公式ヘルプ](https://support.google.com/calendar/answer/37648?hl=ja)にも記載されています。

URLはカレンダーを閲覧できる秘密のリンクです。この拡張は `chrome.storage.local` に保存し、Googleからの取得だけに使用します。Chromeの同期ストレージや独自サーバーには送信しません。Chrome / Edgeではコンテンツスクリプトからストレージへのアクセスも制限しています。再生スクリプトは各ブラウザーともページのMAIN worldで動作し、拡張のストレージAPIを使用しません。接続解除でURL・予定・履歴を削除します。OS上のブラウザプロファイル自体は暗号化する設計ではないため、URLを共有したりリポジトリに保存したりしないでください。

## 番組を登録

Googleカレンダーに、番組の**開始・終了時刻**を指定した予定を作り、説明欄または場所にradikoのURLを入れます。

既存の予定で「場所」に放送局のライブURLを記載している場合も、そのまま利用できます。説明欄への転記は不要です。両方にURLがある場合は、説明欄で認識したURLを優先します。

```text
タイトル: お気に入りのラジオ番組
日時: 毎週日曜 15:00〜16:00
説明: https://radiko.jp/#!/live/TBS
```

以下のURLを認識します。

- 放送局のライブURL：`https://radiko.jp/#!/live/TBS`
- 共有URL：`https://radiko.jp/share/?sid=TBS&t=20260927150000`
- 番組URL：`https://radiko.jp/#!/ts/TBS/20260927150000`

radikoの「Googleカレンダーに追加」で説明欄に入る番組URLも対象です。**どの形式でも放送局を抽出し、カレンダーの開始時刻にライブ放送を再生します。** タイムフリー再生や録音は行いません。番組名だけでは放送局を特定しません。終日予定、URLのない予定、終了時刻のない予定は対象外です。

radikoの放送遅延に合わせたい場合は、各予定の説明欄に独立した行で `遅延: 30秒` と記入してください。開始・終了を両方30秒遅らせます。例えば15:00〜16:00の予定は15:00:30〜16:00:30に再生します。放送局に合わせて秒数を変えられ、繰り返し予定にも適用されます。秒数は0以上の整数で指定します。URLが「場所」にある予定でも利用できます。予定一覧には調整後の時刻を表示します。ブラウザのアラームや再生準備による追加の遅れは発生する場合があります。

設定画面の「放送局データで遅延を自動調整する」をONにして「保存して同期」を押すと、radikoの公開放送局データの `simul_max_delay` を秒数として使います。初期状態はOFFです。説明欄の有効な指定を優先し、自動値に加算はしません。`遅延: 0秒` ならその予定は調整しません。未指定や不正な書式では自動値を使い、データのない局や自動調整OFFの場合は調整しません。再生中の番組の終了時刻は変更せず、次回の再生から適用します。遅延データは端末内に保存し、通常24時間ごとに更新します。更新失敗時は保存済みの値を使って警告を表示し、初回取得失敗時は予定を同期せずエラーを表示します。

繰り返し予定、除外日、個別の日時変更、キャンセルに対応します。日時はカレンダーのタイムゾーンに従い、画面には日本時間で表示します。タイムゾーン指定のない予定はカレンダーの `X-WR-TIMEZONE`、それもない場合は日本時間として扱います。

## ON / OFF

- 拡張のポップアップで「予約再生」を切り替えます。ツールバーのバッジにも `ON` / `OFF` が表示されます。
- **Alt + Shift + R** なら、ポップアップを開かず切り替えられます。Chrome / Edgeの割り当ては `chrome://extensions/shortcuts` / `edge://extensions/shortcuts` で変更できます。Firefoxでは `about:addons` → 歯車メニュー →「拡張機能のショートカットを管理」で変更できます。
- 初期状態はOFFです。OFF→ONに切り替えると、その時点で放送中の予定も途中から再生します。例えば12:00〜13:00の予定があれば、12:05にONにすると再生を開始します。一度再生・停止した番組も、終了前ならOFF→ONで再開できます。終了済みの予定は再生しません。
- OFFにすると、非表示プレーヤーを終了して再生を止めます。「今の再生を停止」なら予約再生はONのままで現在の再生だけを止めます。
- 「予定の終了時刻に再生を止める」は初期状態でONです。OFFの場合も、次の番組が始まれば前の非表示プレーヤーを終了して切り替えます。
- ポップアップで一時停止・再開、音量（0〜100%）、ミュート・ミュート解除を操作できます。音量とミュートは次の番組にも引き継ぎます。ポップアップを閉じても再生や一時停止の状態を維持します。ライブ放送自体は進み、一時停止は録音やタイムフリー機能ではありません。
- 手動で開いたradikoタブは再生操作の対象にしません。

## 動作条件と制約

- **PCが起動し、ブラウザが動作している必要があります。** 拡張はPCをスリープから復帰させません。[Chromeのアラーム仕様](https://developer.chrome.com/docs/extensions/reference/api/alarms)により、開始・終了は数十秒以上遅れることがあります。ONにした後に始まった予定は、スリープ復帰時に開始から2分以内、かつ放送終了前の場合だけ自動再生します。それを過ぎても、OFF→ONに切り替えれば放送中の予定を途中から再生できます。
- 次の7日分を保持し、1分ごとにGoogleから再取得します。Google側のiCal更新が遅れることもあるため、直前に変更した場合は「更新」を押し、一覧への反映を確認してください。
- 通信エラー時は前回の予定を保持します。最終同期から24時間を超えると新たな再生を行いません。通信が切れている間の変更・取消は反映できません。
- 予定が重なったら、先に始まった番組を優先し、重なった予定を履歴にスキップとして記録します。同時刻は予定ID順で1件を選びます。
- radikoのログイン、聴取エリア、利用プランは通常のradikoと同じです。再生は拡張内の非表示ページに埋め込んだradikoで行います。予約時刻にタブや別ウィンドウを開かず、作業中のフォーカスを切り替えません。ログインが必要な場合は、利用者が通常のradikoでログインしてからOFF→ONで再試行してください。既存のログインセッションを非表示プレーヤーへ引き継ぎます。ブラウザのCookie設定により、ログインが引き継がれない場合もあります。
- **ブラウザの自動再生制限により再生がブロックされる場合があります。** 事前にradikoを手動再生し、音量とサイト設定を確認してください。Edgeではradikoの「メディアの自動再生」を許可してください。手動再生を一度行っても、すべての環境で無人再生を保証するものではありません。[Chromeの自動再生ポリシー](https://developer.chrome.com/blog/autoplay)を回避する処理はありません。
- ページの準備が遅れた場合に備え、未再生で対象局の再生ボタンが操作可能な場合だけ、5秒間隔で最大5回まで再生を試みます。再生開始後や読み込み中の音声を、再クリックで止めることはありません。
- Chrome / Edgeでは埋め込みに必要な `offscreen` と `declarativeNetRequestWithHostAccess` 権限を使用します。Firefox版では `offscreen` を要求せず、同じヘッダー変更用権限を使用します。後者は、この拡張自身からradikoへ行うiframe読み込みの `X-Frame-Options` ヘッダーだけを除去するために使用し、停止時にルールを削除します。通常のタブ・別の拡張の通信・その他のヘッダーは変更しません。radikoの認証や聴取制限は変更しません。
- 終了時刻には専用アラームで非表示プレーヤーを終了します。一時停止中・ミュート中・再生確認に失敗した場合も、「予定の終了時刻に再生を止める」がONなら終了時刻に終了します。
- ボタンをクリックしただけでは成功扱いにしません。ページ内の音声要素に加え、radikoが生成する画面に配置されないAudioオブジェクトの時間進行も確認します。音量0やミュートは利用者の設定として維持し、再生の進行確認と区別します。OSのミュートやスピーカーの状態までは確認できません。55秒程度で進行を確認できなければ履歴に失敗を表示します。再生・認証エラー時は対象iframeを破棄し、連続ダイアログと再試行を止めます。ログイン・聴取エリア・接続を確認し、OFF→ONで再試行してください。
- 非表示プレーヤーでは、radikoのヘッダーテンプレートに省略時の表示用オプションを補います。埋め込みでエリアCookieを保存できない場合は、radiko自身が判定・選択して書き込んだエリア値だけをページ内で保持します。広告向けプロフィールの入力フォームは表示せず、拡張の再生ボタン操作時だけサイト自身の再生コールバックを呼びます。プロフィールの入力・送信やログインCookieの変更は行いません。
- 非表示再生の開始時に、既存のradiko_session Cookie（HttpOnlyでないもの）だけを読み取り、対象のradikoプレーヤーへ渡します。埋め込み内でCookieを読み取れない場合の音声認証に使用し、永続保存・ログ出力・独自サーバーへの送信は行いません。Cookieの変更や会員資格の変更は行いません。
- radikoのページ構造が変更されると、再生操作が動作しなくなる場合があります。

## 最初の動作確認

1. radikoを開き、対象局を手動で再生できることを確認します。
2. 2〜3分後に始まり、1分程度で終了するテスト予定をGoogleカレンダーに作ります。
3. 拡張の「更新」を押し、予定一覧に表示されたことを確認してONにします。
4. 別のタブで入力やスクロールなどを続けながら予定時刻を迎え、タブや別ウィンドウが開かず、操作中のフォーカスも変わらずに音が出ることを確認します。ポップアップで一時停止・再開・音量・ミュート解除を試し、ポップアップを閉じても再生が続くことと、終了時刻に止まることを確認します。
5. 次のテストでは再生中にOFFにして停止を確認します。
6. OFFのまま別の予定時刻を迎えても再生しないことを確認します。

ユーザーのカレンダー接続・radikoログイン・実際の音声出力を含めた確認は、この手順で行ってください。
